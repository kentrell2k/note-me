# Note Me

Static site. No build step.

## Deploy (about 15 minutes)
1. Create a new GitHub repo named `note-me`, upload `index.html` and this README.
2. On vercel.com choose Add New, Project, import the repo, then Deploy. Framework: Other. No settings needed.
3. You get a link like https://note-me.vercel.app. Open it on your phone.

## Known limits (day one)
- Notes are stored in the browser on each device. No sync until Supabase accounts are added.
- Demo sign-in only (any email). Not secure yet.
- The Google Calendar button only works inside claude.ai.
- Subscribe button is a demo. No real charge.
